# Denis Genschel – Business Automation · Version 4.3

Diese Version basiert auf Version 4.2 und ergänzt ausschließlich die beiden von dir hochgeladenen Bilder:

- **Startseite, erster Bildschirm:** `assets/hero-vorher-nachher.webp` statt der Workflow-Illustration.
- **Über mich:** `assets/denis-portrait.webp` enthält nun das neue Porträt.

## Aktualisierung im GitHub-Repository

1. Ersetze `index.html` im Hauptverzeichnis.
2. Ersetze `assets/style.css`.
3. Lade `assets/hero-vorher-nachher.webp` neu hoch.
4. Ersetze `assets/denis-portrait.webp`.
5. Speichere/committe die Änderungen auf `main`. Cloudflare Workers veröffentlicht sie bei aktivierter GitHub-Verbindung automatisch.
6. Lade die Website neu (auf dem Mac gegebenenfalls Cmd+Shift+R), falls noch Bilder aus dem Browser-Cache erscheinen.

Alle weiteren Dateien können unverändert bleiben. Das WebP-Format reduziert die Dateigröße bei gleichbleibendem Bildmotiv.

Die bisherigen offenen Punkte zur Einrichtung von Formspree und Google Ads werden durch diese Bildänderung nicht berührt.
