# Version 4.4 – neue Farbpalette (Petrol / Sonnengelb)

Die Verkaufswebsite wurde auf die besprochene Farbpalette umgestellt:

- Warmweiß `#FAF9F6`: großflächige Hintergründe
- Anthrazit `#25282B`: Haupttexte und Überschriften
- Petrolblau `#185C70`: Marke, hervorgehobene Worte, Links, Nebenakzente und Abschlussbereich
- Sonnengelb `#FFD45A`: primäre Anfragebuttons und gezielte Hervorhebungen

Basis: Version 4.3. Unverändert bleiben Inhalte, Videos, Porträt, Vorher-Nachher-Hauptbild, sieben Kartenbilder, Einsparechner, Anfrageformular, Cookie-Auswahl, Landingpages und Preisgestaltung.

## Update auf GitHub

Für diesen **reinen Farbwechsel** genügt es, folgende Datei in `main` zu ersetzen:

`assets/style.css`

Optional können die HTML-Dateien ersetzt werden: Es wurde dort lediglich die mobile Browserleistenfarbe von `#fffdf7` auf `#FAF9F6` angepasst.

Für eine vollständige Neueinrichtung ist die komplette ZIP-Version enthalten.

Nach einem GitHub-Commit (wenn das Cloudflare-Autodeployment aktiviert ist) wird die Änderung veröffentlicht. Bitte Browsercache aktualisieren.

**Wichtig:** Formspree und Google Ads können weiterhin erst nach Eintragen der echten Kennungen sowie rechtlicher Prüfung produktiv eingesetzt werden. Dies wurde durch den Farbwechsel nicht verändert.
